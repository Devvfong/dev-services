Quick Start

🪟 Windows — PowerShell
Run as Administrator for best results.
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/Devvfong/dev-services/master/dist/DevServices.standalone.ps1 | iex
🐧 Linux / Ubuntu — Terminal
Works with Bash on Ubuntu/Debian-based distros.
bash <(curl -fsSL https://raw.githubusercontent.com/Devvfong/dev-services/master/dist/DevServices.linux.sh)
